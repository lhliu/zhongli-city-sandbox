## 未完成與原因

1. **GeoJSON 匯入**：GeoJSON 是經緯度，但目前底圖是「圖面座標模式」（沒有地理校準）。要先取得 ≥6 個已知 TWD97 座標的控制點（路口或地籍點），才能把經緯度放到正確位置。函式庫已完成（`src/lib/calibration`），缺控制點資料與校準頁 UI。
2. **S3 疊圖校準 UI**：S3 沒有比例尺，需控制點對齊 S2；仿射與 RMSE 函式已完成並測試，介面未做。
3. **IndexedDB 草稿**：目前直接存伺服器並顯示已儲存／衝突；離線草稿未做。
4. **部署與 Access**：需 KC 在 Cloudflare 後台操作（README 有步驟）。
5. **備份還原演練**：需正式環境。
6. **P1（AI 解析、GLB、左右比較）**：尚未開始。
7. **真實建案資料**：0 筆。規格禁止編造；等 KC 用 CSV 或介面填入有證據的資料。
